## 기술 조건
- 정적 사이트 (HTML/CSS/JS), 외부 라이브러리 최소화
- 반응형: 데스크톱 1440 / 모바일 375
- 폰트
  - 영문 타이틀/디스플레이: **Garamond — Adobe Fonts(Typekit) 킷 `zhv7ywn`** 〔확정〕
    `<link rel="stylesheet" href="https://use.typekit.net/zhv7ywn.css">`
    - 패밀리: **Garamond Premier Pro** → CSS `font-family: "garamond-premier-pro", ...` 〔확정〕
    - Garamond Premier Pro는 **옵티컬 사이즈**(caption / regular / subhead / display)를 가진다. 큰 타이틀에는 display·subhead 옵티컬을 쓰고 본문 옵티컬을 확대해서 쓰지 않는다 — 확대하면 획이 두꺼워지고 자간이 벌어져 둔해진다. 킷에 어떤 옵티컬·웨이트를 담았는지 확인 후 필요한 것만 추가(로딩 무게 관리).
    - ⚠️ Typekit 킷은 **도메인 잠금**이다. 킷 설정에 `localhost`(로컬 개발)와 실제 라이브 도메인이 **둘 다** 등록돼 있어야 한다. 안 그러면 문서가 경고한 "로컬↔라이브 깨짐"이 그대로 발생.
    - 폴백 스택: `"garamond-premier-pro", "EB Garamond", "Adobe Garamond Pro", Garamond, "Times New Roman", serif`
  - 한글 명조 [서체명] / 라벨 자간넓은 [서체명] (미정 — 라이브 도메인 등록 후 최종)
- 접근성: alt, 키보드 포커스, prefers-reduced-motion

## E. impeccable 사용법 (명령어 몰라도 됨 — 클로드코드에 말로 시키기)

impeccable = 클로드코드가 만든 웹의 "AI 티"를 없애고 라바섬 톤으로 다듬는 도구.
검은 창(터미널)에 뭘 칠 필요 없이, **클로드코드한테 아래 문장을 그대로 말로 시키면** 된다.
(클로드코드가 명령을 알아서 실행함. 대표는 물어보는 것에만 답하면 됨.)

### 1) 설치 + 브랜드 심기 (프로젝트당 한 번)
클로드코드에 이렇게 말한다:
> "이 폴더에 impeccable 설치하고, /impeccable init 실행해줘. 브랜드는 아래 값으로 세팅해줘.
> - 종류: brand (마케팅/랜딩)
> - 컬러: 아이보리 #F6F0E5 / 앰버골드(대표색) / 웜다크브라운 #14110E
> - 타이포: 한글 명조 + 영문 디스플레이 세리프 + 앰버색 라벨
> - 무드/보이스: 절제·연구적·따뜻함 (따뜻한 연구 아카이브)
> - 피할 것(anti-references): 차가운 임상 화이트, 카페24 몰 느낌, seed 초록, AI 슬롭(Inter·보라 그라데이션·카드 남발)"

→ 이러면 impeccable이 깔리고 라바섬 톤이 저장됨(이후 모든 다듬기가 이 톤을 따름).

### 2) 페이지 만들기
C의 프롬프트를 붙여넣어 9섹션을 만든다.

### 3) 다듬기 — 필요한 걸 말로 시킨다
아래 문장을 클로드코드에 그대로 말하면 됨:
- "impeccable로 전체 한번 리뷰해줘" → 어디가 어색한지 짚어줌
- "히어로 타이포 impeccable로 다듬어줘" → 명조↔세리프 대비·크기 정리
- "S3 레이아웃 impeccable로 정리해줘" → 360° 제형+골드 수치 간격
- "스크롤 애니메이션 impeccable로 자연스럽게 해줘"
- "impeccable로 마지막 마감(polish) 해줘" → 출시 전 전체 정리
- 톤 조절: "여기 더 세게(bolder)" / "여기 더 차분하게(quieter)"

### 순서 요약
설치·브랜드 세팅(한 번) → 프롬프트로 빌드 → "리뷰해줘" → "다듬어줘"(타이포·레이아웃·애니메이션) → "마감해줘"

### 참고
- 한 번 세팅하면, 이후 UI를 고칠 때마다 impeccable이 자동으로 "AI 티"를 잡아줌.
- 대표가 직접 칠 명령어는 없음. 전부 클로드코드에 말로 시키면 됨.
- 크레딧 절약: 클로드 디자인은 히어로 1~2컷 감 잡는 데만, 빌드·다듬기는 클로드코드+impeccable에서.
