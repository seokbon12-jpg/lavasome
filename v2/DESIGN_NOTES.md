## 6. 확인 필요

1. **할인율**: 클렌저 48,000→24,000, 비타C 64,000→39,800이 라이브에서 0%로 나옴 → 정확한 할인율(또는 Cafe24 할인 설정 수정)
2. **카운트다운 종료 시각**: `data.js`의 `ends`는 라이브 캡처 시점("03일 12:12") 기준 임시값 `2026-10-31 23:59`. 실제 할인 종료일 필요
3. **NAVER 링크** 주소(푸터 FOLLOW) — 지금 `#`
4. **필터 분류**를 Cafe24 상품 분류로 만들지 여부(아래 7절)
5. **GNB 링크**: Shop·리뷰는 Cafe24 기본 경로(`/product/list.html`, `/board/product/list.html?board_no=4`)로 넣어 둠 — 실제 분류 번호 확인

## 7. Cafe24 모듈 대응

변수 이름은 Cafe24 기본 스킨 기준이다. 쓰는 스킨 버전에 따라 다를 수 있으니 스마트디자인 편집기에서 확인한 뒤 바꾼다.

| v2 | Cafe24 | 옮기는 방법 |
|---|---|---|
| 띠 배너 | 레이아웃 `layout/basic/layout.html` 상단 HTML | 그대로 붙여 넣음. 닫기는 `main.js`의 띠 부분만 |
| GNB | 레이아웃 헤더 + `Layout_statelogon/off`(로그인 상태), `Layout_orderBasketcount`(장바구니 수), 검색 `Layout_SearchHeader` | 메뉴 6개는 고정 링크. 아이콘 3개 자리에 모듈 |
| 쿠폰 | 회원가입 쿠폰은 쇼핑몰 쿠폰 설정 + 팝업 HTML | 카드 HTML·CSS 그대로, "오늘 하루 열지 않기"는 `main.js` 로직(localStorage) |
| 히어로 | 메인 `index.html` 직접 HTML(또는 배너 관리) | `data.js`의 slides를 HTML로 옮기거나 그대로 사용 |
| 제품 카드 | 메인 진열 `module="product_listmain_1"` — `{$product_name}`, `{$product_summary_desc}`(부제), `{$product_custom}`(정가), `{$product_price}`(판매가), 품절 아이콘, 장바구니·옵션보기 버튼 변수 | 카드 마크업(`.pc`)을 모듈 반복부에 넣고 변수로 치환. `data-tags`는 상품번호 기준 매핑 표(`data.js` products.tags)로 JS가 붙임 |
| 피부 고민 필터 | (방법 A) JS 매핑만 — 지금 방식, 상품 수정 없음 / (방법 B) 상품 분류 5개를 만들고 `product_listmain` 분류별 진열 | A로 시작 → 상품이 늘면 B |
| 카운트다운 | 상품 할인 기간(타임세일) 변수 또는 앱 | 종료 시각을 `data-ends`에 넣으면 `main.js`가 그대로 계산 |
| 시그니처·사용법·브랜드 한 줄 | 메인 `index.html` 직접 HTML | 그대로 |
| 인스타그램 | 인스타그램 위젯 앱(또는 외부 피드 위젯) | `.ig` 그리드 안에 위젯 출력. 6개·1:1 유지 |
| 푸터 | 레이아웃 푸터 — `{$company_name}`, `{$president_name}`, `{$company_regno}`, `{$network_regno}`, `{$mall_addr1}`, `{$phone}`, `{$cpo_name}`, `{$cpo_email}` | 텍스트를 변수로 치환 |
| 글꼴 | 파일 업로드(`/web/upload/…`) 또는 CDN | Pretendard는 jsDelivr CDN으로 바꿔도 됨. 나머지 3종은 Google Fonts 그대로 |

## 9. 자가 점검 — 라바섬으로 읽히는가, LIFTON으로 읽히는가

- 라바섬에서 온 것: 로고, 네이비·브론즈, 국문 명조 헤드라인, 제주 라인업 실사·용암석 패키지·페트리 성분 사진, 135,000ppm 브론즈 배지, 남색 "바다" 장면, 둥근 20px 프레임, 라이브 문구 전부.
- LIFTON에서 온 것: 12컬럼 그리드와 8pt 리듬, 헤어라인 두 줄 + sticky 라벨, 모노 라벨, 섹션당 1회 모션, sticky stage.
- LIFTON처럼 보일 위험이 있던 곳과 조치
  - 섹션 라벨: 모노 대문자 + 회색 선이 LIFTON과 같음 → 점을 **브론즈**로, 라벨 옆 제목을 **국문 명조**로 해서 첫인상은 라바섬 쪽.
  - 수평선 곡선: LIFTON Line과 같은 원리 → 색을 브론즈로, 의미를 "바다 수평선"으로 두고 성분 행에만 사용.
  - 전체가 밝고 차가워질 위험 → 브랜드 한 줄을 남색 장면으로 바꿔 라바섬 고유의 깊은 색을 한 번 보여 줌.
- 판단: 첫 화면(제주 라인업 실사 + 명조)과 시그니처(용암석 패키지 + 페트리)에서 라바섬으로 읽힌다. 남은 위험은 제품 카드 사진 해상도 — 누끼 원본이 오면 가장 크게 좋아지는 부분.
