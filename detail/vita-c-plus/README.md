# Filler Vita-C⁺ Ampoule — 상세페이지 (단독 작업본)

라바섬 사이트와 연결하지 않은 별도 작업물입니다. 메뉴·링크·배포 워크플로에 들어가지 않습니다.

```
index.html      상세페이지 (폭 860px, 섹션 14개 = s01 … s14)
style.css       디자인 · 애니메이션
img/            사진 (제품 컷, 원료 샬레, 제주 컷 — 기존 라바섬 자산에서 가공)
fonts/          이 페이지에 쓰인 글자만 담은 Google Fonts 조각 (OFL)
export/         섹션별 정지 JPG(14장) + 움직이는 섹션 GIF(11장)
tools/          export.mjs(내보내기) · make-gif.py(GIF 묶기) · pickfonts.py(글꼴 조각 다시 뽑기)
```

## 보기
`index.html` 을 브라우저로 열면 됩니다. `index.html?still` 은 모든 움직임이 끝난 정지 화면입니다.

## 애니메이션 규칙
- 모든 움직임은 CSS 애니메이션이고 주기가 6초로 같습니다(`--T`).
- GIF 는 6초 한 바퀴를 프레임 단위로 찍어 만들기 때문에 이음매 없이 반복됩니다.
- 움직이는 섹션: 01 히어로(병 위 빛) · 02 135,000 카운트 · 03 물결 고리 · 04 솔루션 밑줄 ·
  05 pH 표시 · 06 2중 레이어 · 07 안정성(바이알 갈변 비교) · 08 임상 수치 · 11 사용 방법 · 12 루틴 · 13 체크

## 다시 내보내기
```
npm i -D playwright      # 처음 한 번
node tools/export.mjs export            # 전체
node tools/export.mjs export --only s07 --fps 15 --scale 2
```
