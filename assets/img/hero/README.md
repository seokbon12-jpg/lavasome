# 히어로 사진 (4장)

올려주신 4장을 아래 이름으로 최적화해 넣어뒀습니다. 원본은 `original/` 에 그대로 보관돼 있습니다.
교체할 때는 **같은 파일명으로 덮어쓰면** 됩니다.

| 파일명 | 내용 | 권장 비율 / 크기 |
|---|---|---|
| `hero-bg.jpg` | 배경 — 제주 해안 풀블리드 | 가로 2400px 이상, 16:9 내외 |
| `hero-01.jpg` | 모델컷 | 세로 3:4 |
| `hero-02.jpg` | 현무암 (콜라주 중앙, 가장 큼) | 세로 3:4.6 |
| `hero-03.jpg` | 용암석 클로즈업 | 가로 4:3 |

### 최적화 내역

| 파일 | 원본 | 결과 |
|---|---|---|
| `hero-bg.jpg` | 24.5 MB PNG (4000px) | 796 KB JPEG (2400px) |
| `hero-01.jpg` | 0.5 MB PNG | 40 KB JPEG |
| `hero-02.jpg` | 1.1 MB PNG | 207 KB JPEG |
| `hero-03.jpg` | 0.8 MB PNG | 83 KB JPEG |

알파 채널이 있었지만 실제 반투명 픽셀이 0.3% 미만(가장자리뿐)이라 JPEG로 변환했습니다.
배경 24.5MB를 그대로 쓰면 히어로가 뜨는 데만 수 초가 걸립니다.

`.hero__shot` 의 `aspect-ratio` 는 각 사진의 실제 비율에 맞춰뒀습니다.
다른 비율의 사진으로 바꾸면 그 값도 같이 고쳐야 잘리지 않습니다.

- 파일이 없으면 `main.js` 가 `<img>` 를 걷어내고 자리표시 그라디언트만 남깁니다.
- 배경은 좌측에 텍스트가 얹히므로 **왼쪽 절반이 비교적 비어 있는 컷**이 좋습니다.
  (`.hero__scrim` 이 왼쪽을 밝게 덮지만, 원본이 복잡하면 가독성이 떨어집니다.)
- 파일명을 바꾸고 싶으면 `index.html` 히어로 블록의 `src` 만 고치면 됩니다.

## 움직임

각 층은 `data-parallax` 값으로 스크롤 대비 이동 비율이 정해집니다.

| 층 | 값 | 체감 |
|---|---|---|
| 배경 | `0.28` | 가장 느리게 따라옴 (멀리) |
| 흰 패널 | `0.06` | 거의 고정 |
| 모델컷 | `-0.10` | 페이지보다 살짝 빠르게 |
| 현무암 | `0.12` | 느리게 |
| 용암석 | `-0.18` | 가장 빠르게 (가까이) |

값을 키우면 시차가 커집니다. `prefers-reduced-motion` 이 켜진 환경에서는 전부 멈춥니다.
